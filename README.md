# Pharmacy Management System

Student ID: 24MIS0140

A Flask-based pharmacy inventory and billing application developed
in three versions as a DevOps project.

## Features

- Add medicines and update stock
- Generate bills
- View bill details
- Validate stock availability
- Health-check endpoint

## Version roadmap

- v1: Basic inventory and billing
- v2: Persistent SQLite storage and improved validation
- v3: Enhanced dashboard, bill history and low-stock alerts

## Technology stack

- Python and Flask
- Git and GitHub
- Jenkins
- Docker and Docker Hub
- Kubernetes

python -m venv .venv
